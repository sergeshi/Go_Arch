# Go_Arch

Инструмент для архитектурных скетчей и игровых блокаутов в стиле SketchUp + гизмо из игровых движков.

## Возможности (в разработке)

- 3D-холст с навигацией как в SketchUp
- Инструменты: линия, прямоугольник, круг, многоугольник, дуга
- Редактирование: перемещение, поворот, масштаб, выдавливание
- Выделение точек / рёбер / граней
- Группировка
- Гизмо трансформации (как в Unity / Blender)

## Установка

```bash
pip install -r requirements.txt
python main.py
```

## Управление камерой (SketchUp-стиль)

- **Средняя кнопка мыши** — Orbit (вращение вокруг точки)
- **Shift + Средняя** — Pan (панорамирование)
- **Колёсико** — Zoom
- **Правая кнопка** — контекстное меню (позже)

## Структура проекта

```
Go_Arch/
├── main.py
├── requirements.txt
├── core/           # сцена, камера, геометрия, математика
```
